# LinkedIn Post — November 11, 2026

Meet Tina. Tina's a builder.

You ask Tina to put up some shelves. She turns up on time, measures everything, drills the holes, fits the brackets. Lovely job.

Seven out of ten things on your list? Done. Perfectly.

The shelves just don't hold anything. She forgot the wall plugs.

---

That's basically what a new benchmark from Alibaba and a few universities found about AI coding agents this week.

They pulled 273 tasks from real user coding sessions. Not toy puzzles. Actual stuff people asked for. Then they graded each one against hidden checklists written by experts. 2,331 checks in total.

The best agent they tested hit about 70% of the checks on average.

But it fully finished only 26.4% of the tasks.

About one in four.

And the harder it got — changes across lots of files, a few different kinds of change in one go — the worse every model did.

---

None of this surprises me, honestly.

I've been writing software since 2001. I've seen plenty of code that was "mostly done." Some of it was mine. Mostly done is a great feeling right up until someone actually uses it.

This is exactly why I bang on about tests so much.

A test doesn't care that you got 70% of the way there. It's green or it's red. Write the tests first, and suddenly "mostly done" has nowhere to hide. It doesn't matter if the code came from me, from a junior dev, or from an agent that writes faster than I can read.

I use these tools every day. They're brilliant. They've changed how I work, quite a lot.

But they're Tina. Fast, keen, and really good at the bits you can see.

Someone still has to check the wall plugs.

How are other folks keeping AI-written code honest? Tests first, careful reviews, or something else entirely?
